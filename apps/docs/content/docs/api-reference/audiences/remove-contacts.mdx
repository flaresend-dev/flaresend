---
title: Remove contacts from an audience
description: Take up to 5,000 contacts out of an audience without deleting them.
method: DELETE
---

<Endpoint method="DELETE" path="/v1/audiences/:id/contacts" />

<ApiPage>
<ApiMain>

Removes contacts from the audience. The contacts stay in the project and in their other audiences. IDs that are not in the audience are ignored, so this call does not fail on unknown IDs.

This `DELETE` request takes a JSON body.

## Path parameters

<Fields>

<ParamField path="id" type="string" required>
  The audience ID.
</ParamField>

</Fields>

## Body parameters

<Fields>

<ParamField body="contactIds" type="string[]" required>
  1 to 5,000 contact IDs.
</ParamField>

</Fields>

## Response

<Fields>

<ResponseField name="removed" type="number">
  How many contacts were actually in the audience and are now removed.
</ResponseField>

</Fields>

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `missing_body` | The request has no body. |
| 400 | `invalid_body` | `contactIds` is missing, empty or has more than 5,000 entries. |
| 404 | `audience_not_found` | No audience with that ID in this project. |

</ApiMain>
<ApiAside>

<ApiExample title="Request">

```ts tab="Node.js" tab-group="lang"
import { Flaresend } from '@flaresend/client';

const flaresend = new Flaresend({
  apiKey: process.env.FLARESEND_API_KEY!,
  baseUrl: 'https://mailer.example.com',
});

const { removed } = await flaresend.audiences.removeContacts('aud_01K6C2A7F3H5J8K1M4N6P9Q2RS', [
  'ct_01K6C1M3R8T2V9X4Z6B7N5P0QA',
]);
```

```bash tab="cURL" tab-group="lang"
curl -X DELETE https://mailer.example.com/v1/audiences/aud_01K6C2A7F3H5J8K1M4N6P9Q2RS/contacts \
  -H "Authorization: Bearer $FLARESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "contactIds": ["ct_01K6C1M3R8T2V9X4Z6B7N5P0QA"] }'
```

</ApiExample>
