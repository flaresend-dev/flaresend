---
title: List audience contacts
description: Page through the contacts in one audience, newest first.
method: GET
---

<Endpoint method="GET" path="/v1/audiences/:id/contacts" />

<ApiPage>
<ApiMain>

Returns the contacts in the audience, ordered by when the contact was created, newest first. Unsubscribed contacts are included; check each contact's `unsubscribed` field. The list is cursor-paginated, see [Pagination](/docs/api-reference/pagination).

## Path parameters

<Fields>

<ParamField path="id" type="string" required>
  The audience ID.
</ParamField>

</Fields>

## Query parameters

<Fields>

<ParamField query="limit" type="number" default="25">
  How many contacts per page, from 1 to 100. Values outside that range are clamped to it.
</ParamField>

<ParamField query="cursor" type="string">
  The `nextCursor` value from the previous page.
</ParamField>

</Fields>

## Response

<Fields>

<ResponseField name="data" type="Contact[]">
  The contacts on this page, with the fields described in [Create a contact](/docs/api-reference/contacts/create#response).
</ResponseField>

<ResponseField name="nextCursor" type="string | null">
  Pass this as `cursor` to get the next page. `null` on the last page.
</ResponseField>

</Fields>

## Errors

| Status | Code | When |
|---|---|---|
| 404 | `audience_not_found` | No audience with that ID in this project. |

</ApiMain>
