---
title: Update an audience
description: Rename an audience.
method: PATCH
---

<Endpoint method="PATCH" path="/v1/audiences/:id" />

<ApiPage>
<ApiMain>

The name is the only thing you can change on an audience. To change who is in it, use [Add contacts](/docs/api-reference/audiences/add-contacts) and [Remove contacts](/docs/api-reference/audiences/remove-contacts).

## Path parameters

<Fields>

<ParamField path="id" type="string" required>
  The audience ID.
</ParamField>

</Fields>

## Body parameters

<Fields>

<ParamField body="name" type="string" required>
  The new name, 1 to 200 characters. Must be unique in the project.
</ParamField>

</Fields>

## Response

The renamed audience, with the fields described in [Create an audience](/docs/api-reference/audiences/create#response).

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `invalid_body` | `name` is missing, empty or over 200 characters. |
| 404 | `audience_not_found` | No audience with that ID in this project. |

<Callout type="warn">
  Renaming to a name another audience already has is not turned into a clean `409 audience_exists` the way [Create an audience](/docs/api-reference/audiences/create) is. The database refuses it and the request fails with `500 internal_error`. Pick a name that isn't taken.
</Callout>

</ApiMain>

<ApiExample title="Request">

```ts tab="Node.js" tab-group="lang"
import { Flaresend } from '@flaresend/client';

const flaresend = new Flaresend({
  apiKey: process.env.FLARESEND_API_KEY!,
  baseUrl: 'https://mailer.example.com',
});

const audience = await flaresend.audiences.update('aud_01K6C2A7F3H5J8K1M4N6P9Q2RS', {
  name: 'Early access',
});
```

```bash tab="cURL" tab-group="lang"
curl -X PATCH https://mailer.example.com/v1/audiences/aud_01K6C2A7F3H5J8K1M4N6P9Q2RS \
  -H "Authorization: Bearer $FLARESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Early access" }'
```
