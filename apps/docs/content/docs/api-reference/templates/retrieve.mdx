---
title: Retrieve a template
description: One template by name. Built-in templates come back rendered with their example data.
method: GET
---

<Endpoint method="GET" path="/v1/templates/:name" />

<ApiPage>
<ApiMain>

Looks the name up the same way a send does: a template stored in the project first, then the [built-in templates](/docs/templates/built-in).

- A **stored** template comes back as saved, with its variables unrendered and its current `version`.
- A **built-in** template comes back with `subject`, `html` and `text` rendered from its example data, so you can see what it looks like. `id`, `version` and the timestamps are `null`.

## Path parameters

<Fields>

<ParamField path="name" type="string" required>
  The template name, for example `order-shipped` or `welcome`.
</ParamField>

</Fields>

## Response

<Fields>

<ResponseField name="id" type="string | null">
  `tmpl_…` for stored templates, `null` for built-in ones.
</ResponseField>

<ResponseField name="source" type="'db' | 'git'">
  `db` for stored templates, `git` for built-in ones.
</ResponseField>

<ResponseField name="projectId" type="string | null">
  `null` for built-in templates.
</ResponseField>

<ResponseField name="name" type="string">
  The template name.
</ResponseField>

<ResponseField name="subject" type="string">
  Stored: the unrendered subject. Built-in: the subject rendered from the example data.
</ResponseField>

<ResponseField name="html" type="string | null">
  Stored: the unrendered HTML. Built-in: the rendered HTML.
</ResponseField>

<ResponseField name="text" type="string | null">
  Stored: the text body or `null`. Built-in: the rendered plain text.
</ResponseField>

<ResponseField name="variables" type="Variable[]">
  `{ name, required, example }` for each variable.
</ResponseField>

<ResponseField name="version" type="number | null">
  The current version of a stored template. `null` for built-in ones.
</ResponseField>

<ResponseField name="createdAt" type="string | null">
  ISO 8601 timestamp, or `null` for built-in templates.
</ResponseField>

<ResponseField name="updatedAt" type="string | null">
  ISO 8601 timestamp, or `null` for built-in templates.
</ResponseField>

</Fields>

## Errors

| Status | Code | When |
|---|---|---|
| 404 | `template_not_found` | No stored or built-in template with this name. |

</ApiMain>

<ApiExample title="Request">

```ts tab="Node.js" tab-group="lang"
import { Flaresend } from '@flaresend/client';

const flaresend = new Flaresend({
  apiKey: process.env.FLARESEND_API_KEY!,
  baseUrl: 'https://mailer.example.com',
});

const template = await flaresend.templates.get('order-shipped');
```

```bash tab="cURL" tab-group="lang"
curl https://mailer.example.com/v1/templates/order-shipped \
  -H "Authorization: Bearer $FLARESEND_API_KEY"
```

</ApiExample>
