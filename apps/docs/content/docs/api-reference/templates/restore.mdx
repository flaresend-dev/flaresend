---
title: Restore a template version
description: Bring back an older version of a stored template as a new version.
method: POST
---

<Endpoint method="POST" path="/v1/templates/:name/restore" />

<ApiPage>
<ApiMain>

Copies the subject, HTML, text and variables of an older version into a **new** version. History is never rewritten: restoring version 2 of a template that is at version 5 creates version 6 with the content of version 2. Sends use it straight away.

Like [Update a template](/docs/api-reference/templates/update), this fails with `409 template_conflict` if the template changes while the restore runs.

## Path parameters

<Fields>

<ParamField path="name" type="string" required>
  The template name.
</ParamField>

</Fields>

## Body parameters

<Fields>

<ParamField body="version" type="number" required>
  The version to restore, a whole number from 1. See [List template versions](/docs/api-reference/templates/versions).
</ParamField>

</Fields>

## Response

The template at its new version. Same fields as [Retrieve a template](/docs/api-reference/templates/retrieve).

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `missing_body` | The request has no body. |
| 400 | `invalid_body` | `version` is missing or not a whole number of at least 1. |
| 404 | `template_not_found` | No stored template with this name. Built-in templates also return this. |
| 404 | `template_version_not_found` | The template has no such version. |
| 409 | `template_conflict` | The template changed while the restore ran. |

</ApiMain>

<ApiExample title="Request">

```ts tab="Node.js" tab-group="lang"
import { Flaresend } from '@flaresend/client';

const flaresend = new Flaresend({
  apiKey: process.env.FLARESEND_API_KEY!,
  baseUrl: 'https://mailer.example.com',
});

const template = await flaresend.templates.restore('order-shipped', 2);
```

```bash tab="cURL" tab-group="lang"
curl -X POST https://mailer.example.com/v1/templates/order-shipped/restore \
  -H "Authorization: Bearer $FLARESEND_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "version": 2 }'
```

</ApiExample>
