---
title: Update a contact
description: Change a contact's name, data or subscription status.
method: PATCH
---

<Endpoint method="PATCH" path="/v1/contacts/:id" />

<ApiPage>
<ApiMain>

Only the fields you send change. Unlike [Create a contact](/docs/api-reference/contacts/create), `null` here clears a field. The email address can't be changed; create a new contact instead.

Setting `unsubscribed` to `false` puts a contact back on your broadcasts. Only do that when the person asked for it. See [Unsubscribe](/docs/contacts/unsubscribe).

## Path parameters

<Fields>

<ParamField path="id" type="string" required>
  The contact ID.
</ParamField>

</Fields>

## Body parameters

<Fields>

<ParamField body="firstName" type="string | null">
  Up to 200 characters. `null` clears it.
</ParamField>

<ParamField body="lastName" type="string | null">
  Up to 200 characters. `null` clears it.
</ParamField>

<ParamField body="unsubscribed" type="boolean">
  `true` makes broadcasts skip this contact.
</ParamField>

<ParamField body="data" type="object | null">
  Replaces the stored data object as a whole. `null` clears it.
</ParamField>

</Fields>

## Response

The updated contact, with the fields described in [Create a contact](/docs/api-reference/contacts/create#response).

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `missing_body` | The request has no body. |
| 400 | `invalid_body` | A field has the wrong type or length. |
| 404 | `contact_not_found` | No contact with that ID in this project. |

</ApiMain>
