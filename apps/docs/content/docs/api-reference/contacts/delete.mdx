---
title: Delete a contact
description: Remove a contact and take it out of every audience.
method: DELETE
---

<Endpoint method="DELETE" path="/v1/contacts/:id" />

<ApiPage>
<ApiMain>

Deletes the contact and removes it from every audience it was in. This can't be undone. Emails already sent to the contact stay in the email log.

If you only want to stop sending to someone, [update the contact](/docs/api-reference/contacts/update) with `unsubscribed: true` instead. That keeps the record, so a later import or upsert doesn't subscribe them again.

## Path parameters

<Fields>

<ParamField path="id" type="string" required>
  The contact ID.
</ParamField>

</Fields>

## Response

<Fields>

<ResponseField name="id" type="string">
  The ID of the deleted contact.
</ResponseField>

<ResponseField name="deleted" type="true">
  Always `true`.
</ResponseField>

</Fields>

## Errors

| Status | Code | When |
|---|---|---|
| 404 | `contact_not_found` | No contact with that ID in this project. |

</ApiMain>

