---
title: List emails across projects
description: Search the email log of every project, or one project by slug.
method: GET
---

<Endpoint method="GET" path="/v1/admin/emails" auth="admin" />

<ApiPage>
<ApiMain>

The admin version of [List emails](/docs/api-reference/emails/list). It takes the same filters and returns the same shape, but covers every project unless you pass `project`. Newest first. Each email includes its recipients but not its event timeline (`events` is `[]`); fetch one email with `GET /v1/admin/emails/:id` for the timeline.

## Query parameters

<Fields>

<ParamField query="project" type="string">
  Only emails from the project with this slug.
</ParamField>

<ParamField query="limit" type="integer" default="25">
  Page size, 1 to 100.
</ParamField>

<ParamField query="cursor" type="string">
  The `nextCursor` from the previous page.
</ParamField>

<ParamField query="status" type="string">
  One email status: `queued`, `scheduled`, `sending`, `sent`, `delivered`, `deferred`, `bounced`, `complained`, `rejected`, `failed`, `test` or `canceled`.
</ParamField>

<ParamField query="to" type="string">
  Matches any recipient (`to`, `cc` or `bcc`). A full address matches exactly; text without `@` matches part of an address, for example `example.com`.
</ParamField>

<ParamField query="from" type="string">
  The sender address, exact match (not the display name).
</ParamField>

<ParamField query="q" type="string">
  Text the subject contains.
</ParamField>

<ParamField query="tag" type="string">
  A tag as `key:value`, for example `kind:welcome`.
</ParamField>

<ParamField query="since" type="string">
  Only emails created at or after this ISO 8601 date-time (with offset).
</ParamField>

<ParamField query="until" type="string">
  Only emails created before this ISO 8601 date-time (with offset).
</ParamField>

</Fields>

## Response

<Fields>

<ResponseField name="data" type="Email[]">
  The emails, with the fields described in [Retrieve an email](/docs/api-reference/emails/retrieve).
</ResponseField>

<ResponseField name="nextCursor" type="string | null">
  Pass it as `cursor` for the next page. `null` on the last page. See [Pagination](/docs/api-reference/pagination).
</ResponseField>

</Fields>

## Errors

| Status | Code | When |
|---|---|---|
| 400 | `invalid_query` | A filter is malformed, for example `tag` without a colon or `limit` over 100. |
| 404 | `project_not_found` | `project` is set and no project has that slug. |
