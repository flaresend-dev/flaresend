---
title: List projects
description: Every project on the mailer, oldest first, disabled ones included.
method: GET
---

<Endpoint method="GET" path="/v1/admin/projects" auth="admin" />

<ApiPage>
<ApiMain>

Returns all projects in one response, ordered by creation time, oldest first. The list is not paginated. Disabled projects are included; check `disabledAt`.

## Response

<Fields>

<ResponseField name="data" type="Project[]">
  The projects. Each one has the fields described in [Retrieve a project](/docs/api-reference/admin/retrieve-project#response).
</ResponseField>

</Fields>

</ApiMain>
<ApiAside>

<ApiExample title="Request">

```ts tab="Node.js" tab-group="lang"
const res = await fetch('https://mailer.example.com/v1/admin/projects', {
  headers: { Authorization: `Bearer ${process.env.FLARESEND_ADMIN_KEY}` },
});
const { data: projects } = await res.json();
```

```bash tab="cURL" tab-group="lang"
curl https://mailer.example.com/v1/admin/projects \
  -H "Authorization: Bearer $FLARESEND_ADMIN_KEY"
```

```bash tab="CLI" tab-group="lang"
flaresend projects list
```
