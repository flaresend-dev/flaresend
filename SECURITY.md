# Security policy

## Supported versions

Security fixes are available in the latest release of each published Flaresend package and in the current `main` branch.

## Report a vulnerability

Use [GitHub's private vulnerability report](https://github.com/flaresend-dev/flaresend/security/advisories/new) to report a security issue. Do not open a public issue for an undisclosed vulnerability.

Include the affected version, the impact, and the steps to reproduce the issue. Do not include live credentials or personal data.

The maintainers will review the report, coordinate a fix, and publish a security advisory when the fix is available.
